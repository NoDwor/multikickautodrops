# MultiKickAutoDrops

[RU](https://github.com/NoDwor/multikickautodrops/blob/main/README.ru.md) · [EN](https://github.com/NoDwor/multikickautodrops/blob/main/README.md)

---

**MultiKickAutoDrops** — это минималистичный инструмент автоматизации для сбора игровых дропов **Rust** с сайта [Kick.com](https://kick.com), **без необходимости реально смотреть трансляции**, и с фармом **нескольких аккаунтов параллельно**.
Приложение работает в фоне, имитируя просмотр стримов через API Kick.com. Это позволяет получать дропы, экономя трафик и ресурсы системы.

## ✨ Возможности

- 🎮 Автофарм дропов **Rust** на Kick.com — видео и аудио **не скачиваются**
- 👥 **Мульти-аккаунт** — положите несколько файлов кук, и каждый фармит **параллельно**, в своём потоке
- 💾 Минимум ресурсов — только API-запросы, без медиапотока
- 📈 Прогресс каждого аккаунта сохраняется между перезапусками (`views/<имя>.json`)
- 🏆 Опциональный **автоклейм** завершённых дропов
- 🌐 Двуязычный интерфейс (RU / EN)

## ⚙️ Как это работает

Приложение открывает **WebSocket-соединение** с вьюер-эндпоинтом Kick и поддерживает «просмотр» активным:

- каждые **~15 секунд** отправляет keep-alive `ping` / handshake;
- каждые **60 секунд** отправляет событие `watch.livestream`, которое Kick засчитывает как время просмотра — **без загрузки видео или аудио**;
- периодически перепроверяет стрим и останавливается, если стример ушёл в **офлайн** или сменил **игру**.

Завершённые награды определяются через drops-API Kick и, если включено, **клеймятся автоматически**.

## 🧩 Установка

### Вариант 1: Готовая сборка (Windows)

1. Откройте раздел [Releases](https://github.com/NoDwor/multikickautodrops/releases)
2. Скачайте последнюю сборку — `KickAutoDrops-windows.zip`
3. Распакуйте архив. Держите папку `locales/` и файл `example_config.ini` **рядом с `KickAutoDrops.exe`**.
4. Установите расширение для экспорта cookies:
   - [Get cookies.txt LOCALLY (Chrome)](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)
   - [Get cookies.txt LOCALLY (Firefox)](https://addons.mozilla.org/en-US/firefox/addon/get-cookies-txt-locally/)
5. Войдите на [kick.com](https://kick.com) и экспортируйте все cookies
6. Сохраните их в `.txt`-файл (например **`cookies.txt`**) **рядом с исполняемым файлом** — можно положить несколько файлов для нескольких аккаунтов (см. раздел «👥 Аккаунты и cookies» ниже)
7. Запустите `KickAutoDrops.exe` (двойным кликом или из терминала)

### Вариант 2: Запуск из исходников

Требуется **Python 3.11+**.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/NoDwor/multikickautodrops.git
cd multikickautodrops

# 2. Установите зависимости
pip install -r requirements.txt
```

3. **Экспортируйте свои cookies с Kick в `.txt`-файл и положите его в эту папку** (см. «👥 Аккаунты и cookies»). Без хотя бы одного файла кук программа напишет «аккаунты не найдены» и закроется.

```bash
# 4. Запустите
python index.py
```

На Windows можно просто дважды кликнуть **`run.bat`** — он сам подхватит `py`/`python` и не закроет окно консоли, чтобы вы видели вывод.

`config.ini` создаётся автоматически из `example_config.ini` при первом запуске — вручную настраивать ничего не нужно.

Либо соберите отдельный исполняемый файл:

```bash
pip install pyinstaller
pyinstaller index.spec   # результат появится в dist/
```

## 👥 Аккаунты и cookies

Программа сама находит все аккаунты по файлам cookies в корне проекта — заранее задавать их количество не нужно.

- Экспортируйте cookies с [kick.com](https://kick.com) расширением **Get cookies.txt LOCALLY** — оно сохраняет файл в формате **Netscape** (первая строка `# Netscape HTTP Cookie File`).
- Положите файл рядом с исполняемым файлом (или в корень проекта при запуске из исходников). **Любой `*.txt` в формате Netscape считается отдельным аккаунтом**, имя произвольное: `cookies1.txt`, `main.txt`, `nick.txt`.
- Нужно **несколько аккаунтов** — просто добавьте несколько таких файлов. Все они фармят **параллельно**.
- `requirements.txt` и прочие не-cookie `.txt` автоматически пропускаются.
- Прогресс каждого аккаунта хранится отдельно в `views/<имя_файла>.json`, а в логах аккаунт помечается именем своего файла.

> ⚠️ Файл cookies содержит ваш `session_token` — это фактически доступ к аккаунту. Такие файлы уже внесены в `.gitignore`; **никогда не коммитьте и не публикуйте их.**

## 🛠 Настройка

Параметры хранятся в `config.ini` (создаётся из `example_config.ini`):

```ini
[general]
language = en          ; язык интерфейса: en / ru
autoclaimdrops = true  ; автоматически забирать завершённые дропы
```
